## About The Project

MetroForge is a browser-based 3D city-building game focused on creating and managing a growing city.

The project is designed to eventually include roads, zoning, buildings, citizens, traffic, public services, utilities, economics, transportation, and a simulated living city.

The game runs directly in a web browser and is designed to be hosted using GitHub Pages.

## Getting Started

### Prerequisites

MetroForge does not currently require Node.js, npm, or a build system.

All that is required is a modern web browser.

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/MetroForge.git
```

Open the project folder:

```bash
cd MetroForge
```

Open `index.html` in your browser.

## Usage

### Camera Controls

| Input            | Action        |
| ---------------- | ------------- |
| Left Mouse Drag  | Rotate camera |
| Right Mouse Drag | Pan camera    |
| Mouse Wheel      | Zoom          |

### Building

Select a tool from the build menu and click on the terrain.

Available tools currently include:

* Select
* Road
* Residential
* Commercial
* Industrial
* Bulldoze
